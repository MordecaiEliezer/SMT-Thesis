# SMT-Thesis

## Statistical Machine Translation (SMT)

### Model

This project uses the IBM Model 1, a word-based translation model that translates text at the word level rather than by phrases or full sentences.

### Dataset

The dataset includes:

- Filipino words and sentences
- Hiligaynon words and sentences

These datasets are paired for training and evaluating the translation model.

### Python (Jupyter Notebook)

The project was developed using Python within Jupyter Notebook, chosen for its flexibility, interactive environment, and strong support for machine learning and natural language processing tasks.

### Libraries Used

- pickle – for saving and loading trained models or serialized data
- numpy – for numerical and array-based computations
- spacy – for natural language processing and tokenization
- tkinter – for creating the graphical user interface (GUI)
- string – for text manipulation and processing
